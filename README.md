# THE SUNDAY PLANET — 22 November 2026 in one image

A program that draws one magazine-cover image summing up the world news of
Sunday 22 November 2026: the COP31 climate talks in Antalya, Türkiye,
where a deal sits on the table awaiting its approval session; IG Metall
calling 23,000 German workers out on a 24-hour strike; and 25 US deportees
arriving in Liberia under a deal capped at 1,200.

`main.py` is pure Python 3 standard library — its own 5x7 block typeface,
its own PNG encoder — and writes `entry.png` into `$MAKEFUN_OUTPUT_DIR`
(default `/output`), byte-identical on every run.
